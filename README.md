I build Discord bots. My main project is **Miyu** (private), a music and community bot on discord.js v14 and Lavalink v4.

## Miyu

[![Node.js](https://img.shields.io/badge/node-%3E%3D22.5-339933?logo=node.js&logoColor=white)](https://nodejs.org)
[![discord.js](https://img.shields.io/badge/discord.js-v14-5865F2?logo=discord&logoColor=white)](https://discord.js.org)
[![Lavalink](https://img.shields.io/badge/Lavalink-v4-orange)](https://lavalink.dev)

- Music from YouTube, YouTube Music, Spotify and SoundCloud, with 11 filter presets and 24/7 mode
- Moderation: antinuke, raid detection, automod, case history and a cross-server ban list
- Leveling, tickets, birthdays, economy, giveaways and games
- Lavalink node health tracking, with players moving to a healthy node if one drops
